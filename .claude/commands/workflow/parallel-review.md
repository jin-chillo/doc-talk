# 병렬 코드 리뷰 실행

3개의 전문 리뷰어 에이전트를 병렬로 실행하여 코드를 다각도로 분석합니다.

## 실행 방법

리뷰 대상: $ARGUMENTS (파일 또는 디렉토리 경로 지정)

## 에이전트 구성

### 에이전트 1: 코드 품질 리뷰어 (Sonnet 모델)
다음 항목을 검토합니다:
- 코드 가독성 및 유지보수성
- 네이밍 컨벤션 및 코딩 스타일 준수
- 함수/클래스 설계 및 책임 분리
- 중복 코드 및 리팩토링 기회
- 성능 최적화 가능성
- 에러 핸들링 적절성

### 에이전트 2: 보안 취약점 검사 (Opus 모델)
다음 항목을 검토합니다:
- SQL 인젝션, XSS 등 보안 취약점
- 민감 정보 노출 (하드코딩된 비밀키, 토큰 등)
- 인증/인가 로직 검증
- 입력 검증 및 sanitization
- 안전하지 않은 의존성 사용
- 보안 베스트 프랙티스 준수

### 에이전트 3: 테스트 커버리지 분석 (Haiku 모델)
다음 항목을 검토합니다:
- 테스트 코드 존재 여부
- 테스트 커버리지 충분성
- 엣지 케이스 및 에러 케이스 테스트
- 테스트 코드 품질 및 가독성
- 모킹 및 테스트 격리 적절성
- 누락된 테스트 케이스 식별

## 병렬 실행 지시

위 3개 에이전트를 **동시에 병렬로** 실행하세요. 각 에이전트는 독립적으로 $ARGUMENTS에 지정된 대상을 분석합니다.

### 1. 요약 (Executive Summary)
- 전체 리뷰 대상 범위
- 발견된 이슈 총 개수 (우선순위별)
- 전반적인 코드 품질 평가
