현재 세션의 비용을 분석하고 최적화 방안을 제안해주세요.

## 분석 항목

### 1. 현재 세션 분석
다음 항목들을 분석해주세요:

- **토큰 사용량 추정**
  - 입력 토큰 수 (프롬프트 + 컨텍스트)
  - 출력 토큰 수 (응답)
  - 총 토큰 수 및 예상 비용

- **모델별 사용 비율**
  - Claude Opus 4.5 사용 비율
  - Claude Sonnet 4.5 사용 비율
  - Claude Haiku 사용 비율
  - 각 모델의 비용 기여도

- **컨텍스트 윈도우 상태**
  - 현재 컨텍스트 크기
  - 최대 컨텍스트 대비 사용률
  - 불필요한 컨텍스트 식별

### 2. 비용 최적화 제안

다음 관점에서 최적화 방안을 제안해주세요:

- **모델 전환 권장**
  - 현재 작업에 적합한 모델 추천
  - Haiku로 처리 가능한 작업 식별 (간단한 코드 생성, 테스트 실행, 포맷팅)
  - Sonnet으로 처리 가능한 작업 식별 (일반적인 코드 리뷰, 리팩토링, 문서화)
  - Opus가 필요한 작업 식별 (복잡한 아키텍처 설계, 보안 분석, 고급 추론)

- **컨텍스트 정리 필요 여부**
  - 세션 재시작 권장 여부
  - 불필요한 파일 제거 권장
  - 컨텍스트 요약 필요성

- **병렬 vs 순차 실행 권장**
  - 독립적인 작업의 병렬 처리 기회
  - Agent 기반 병렬 실행으로 비용 절감 가능한 작업
  - 순차 실행이 더 효율적인 경우

### 3. 출력 형식

다음 형식으로 결과를 제공해주세요:

├─────────────────────────┼────────────────────┼──────────────┤

├─────────────────────────┼────────────────────┼──────────────┤

#### 최적화 제안사항

**우선순위별 권장사항:**

1. **즉시 적용 가능** (예상 절감: XX%)
   - [구체적인 제안 1]
   - [구체적인 제안 2]

2. **단기 개선** (예상 절감: XX%)
   - [구체적인 제안 1]
   - [구체적인 제안 2]

3. **장기 전략** (예상 절감: XX%)
   - [구체적인 제안 1]
   - [구체적인 제안 2]

**모델 전환 권장:**
- 다음 작업은 Haiku로 전환 가능: [작업 목록]
- 다음 작업은 Sonnet으로 충분: [작업 목록]
- Opus 유지 필요: [작업 목록]

**컨텍스트 관리:**
- 세션 재시작 권장 여부: [예/아니오] - 이유: [...]

**실행 전략:**
- 병렬 처리 권장 작업: [작업 목록]
- Agent 활용 기회: [구체적인 시나리오]
