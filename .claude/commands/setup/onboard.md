description: 새 프로젝트 빠른 온보딩 및 플러그인 추천
---

이 프로젝트를 빠르게 온보딩하고 적합한 플러그인을 추천해줘.

**온보딩 프로세스:**

1. **프로젝트 구조 분석**
   - 디렉토리 구조 파악
   - 주요 파일 및 폴더 식별

2. **언어/프레임워크 자동 감지**
   - `package.json` → Node.js/TypeScript
   - `requirements.txt`, `pyproject.toml` → Python
   - `go.mod` → Go

3. **적합한 플러그인 추천**
   - **code-review-plugin**: 코드 리뷰가 필요한 프로젝트
   - **test-automation-plugin**: 테스트가 필요한 프로젝트
   - **web-scraper-plugin**: 웹 스크래핑 관련 프로젝트

**출력 형식:**

```markdown
# 프로젝트 온보딩 리포트

## 프로젝트 개요
- **이름**: [프로젝트명]
- **유형**: [웹앱/CLI/라이브러리]
- **주 언어**: [언어]

## 추천 플러그인
1. **[플러그인명]**: [이유]

## 다음 단계
1. [실행할 명령어]
```
